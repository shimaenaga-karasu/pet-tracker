# ペットトラッカー

おはぎとサナの健康記録アプリ「ペットトラッカー」のプログラムです。
うんち・おしっこ・お薬・ごはんなどの毎日の記録を、家族で共有するためのWebアプリです。

## 大事なこと

- ここに入っているのは**プログラムだけ**です。おはぎとサナの記録データそのものは含まれていません。
- このプログラムは Muse の中で動くように作られているため、**このままでは Muse の外では動きません**。保管とバージョン管理のためのコピーです。
- 普段使うアプリは今までどおり Muse の中のものを使ってください。

## 構成

- `client/` … 画面のプログラム（React）
- `server/` … 記録の保存や読み込みのプログラム
- `drizzle/` … データベースの形を決めるファイル

## 更新について

アプリの更新はレイラが行い、ここにも同じ内容を反映します。
